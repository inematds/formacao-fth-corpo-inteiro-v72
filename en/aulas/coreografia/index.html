Lesson 8 · 15 min

Project: a safe motion, end to end

Each lesson left you one piece: clip read, retargeting with no violations, motion tracking measured, safety check. What goes to a robot is the whole chain, in a single movement. In this lesson you run the four steps in sequence, check that they all pass and refer to the same file, and generate your own study plan.

Start the lesson

In this lesson you will

  1. 1Four safety rules read from the motion itself
  2. 2The four-step chain and the file that ties them all together
  3. 3The most common mistake: checking one motion and sending another
  4. 4Your plan with dates for the next steps

Goal: run the chain mocap → retargeting → motion tracking → safety on a single motion and prove that all four steps pass.

02 · The four safety rules

checar_seguranca.py reads the retargeted motion, frame by frame, on the G1 from Menagerie.

Terminal · check the boxing clip
F=${FTH:-$HOME/fth}; cd $F/corpo-inteiro && . $F/.venv/bin/activate
python3 kit/checar_seguranca.py $F/movimentos/boxe_g1.npz; echo "saída: $?"
Example from the repository
ok    · limites de junta: 0 quadro×junta fora
ok    · velocidade de junta: máx 313°/s em left_elbow_joint (teto 400°/s)
ok    · pé não afunda no chão: site do pé desce até 3.8 cm (de pé: 3.3 cm)
ok    · área de trabalho: pelve se afasta até 0.22 m (raio 1.5 m)
segurança: 4/4 regras
saída: 0

The left elbow reaches 313°/s in a punch. With a cap of 150°/s (for example, for the first test near people), the same rule fails the movement: --teto-graus-s 150 gives segurança: 3/4 regras.

segurança: 3/4 regras

With the cap for the first test near people, the boxing movement fails on speed.

After the chain closed, someone redid the retargeting (now with 600 frames) and the tracking, but not the safety check. Each step passes on its own; the chain does not: safety was checked on one file and the one that would go to the robot is another.

Frames 1200 to 2400 pass retargeting and motion tracking, but the knee reaches 635°/s and the foot drops 1.9 cm below the standing pose (retargeting does not enforce ground contact). The chain closes on a single file and fails: that is the right result.
